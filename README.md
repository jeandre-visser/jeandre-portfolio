# Jeandré Visser Portfolio

Personal portfolio for Jeandré Visser, Co-Founder and CPO at SubTrack.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS v4
- Motion
- Phosphor Icons
- Geist and Geist Mono

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site is a static Vite build and can be deployed directly to Netlify using
`npm run build` with `dist` as the publish directory.
